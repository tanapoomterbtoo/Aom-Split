# Aom Split — หารเหล้า

แอปเว็บเบาๆ สำหรับ**เพื่อนไปกินเหล้าด้วยกัน**  
บันทึกว่าใครจ่ายอะไร · ใครกินเท่าไร · แล้วสรุปว่า **ใครต้องโอนให้ใคร เท่าไหร่**

ไม่ใช่ระบบ POS ร้าน — เป็นตัวช่วยหารบิลในกลุ่มเพื่อน (แนว Splitwise เฉพาะทริปกินดื่ม)

## 🌐 Live (GitHub Pages)

**https://tanapoomterbtoo.github.io/Aom-Split/**

Source: branch `main` · folder `/` (root)

## เปิดใช้งาน

### วิธีเร็ว (เปิดไฟล์ตรงๆ)

```bash
open index.html
# หรือดับเบิลคลิก index.html
```

### ผ่าน static server (แนะนำบนมือถือ / เครือข่ายท้องถิ่น)

```bash
npx --yes serve .
# แล้วเปิด URL ที่ขึ้นในเทอร์มินัล
```

### บันทึกข้อมูลอัตโนมัติ

- ทุกทริป / รายการจ่าย / สถานะโอน ถูก**บันทึกอัตโนมัติ**ในเบราว์เซอร์เครื่องนี้ (`localStorage` · key `aom_split_v1`)
- เปิดเว็บเดิมบนเครื่องเดิม → เจอข้อมูลเดิม
- หน้าแรกมีปุ่ม **ส่งออกสำรอง / นำเข้าสำรอง** (ไฟล์ `.json`) ไว้ย้ายเครื่องหรือกันข้อมูลหาย

### แชร์กับเพื่อนผ่าน Google Sheet (DB กลาง)

กลุ่มเพื่อนใช้ **Google Sheet ชุดเดียว** เป็นฐานข้อมูล:

1. คนหนึ่งตั้ง Apps Script ตาม [`apps-script/README.md`](./apps-script/README.md) → ได้ **Web App URL** + **token**
2. ทุกคนเปิดแอป → การ์ด **Google Sheet (แชร์กับเพื่อน)** → ใส่ URL + token ชุดเดียวกัน → เปิดสวิตช์ → ซิงก์
3. บันทึกทริป/รายการจะอัปขึ้น Sheet อัตโนมัติ · เปิดหน้าทริปจะดึงของล่าสุดจาก Sheet

| | |
|--|--|
| โค้ดฝั่ง Sheet | `apps-script/Code.gs` |
| คู่มือ deploy | `apps-script/README.md` |
| conflict | ใครบันทึกล่าสุดชนะ (`updatedAt`) |

> ยัง cache บนเครื่อง — ออฟไลน์ใช้ต่อได้ แล้วค่อยซิงก์เมื่อมีเน็ต  
> อย่าโพสต์ URL+token สาธารณะ (ใครมีครบทั้งคู่แก้ข้อมูลกลุ่มได้)

## วิธีใช้ (สั้นๆ)

1. เปิด **หน้าแรก** → **สร้างทริปใหม่** ใส่ชื่อทริปและชื่อเพื่อน
2. เพิ่ม**สมาชิก**และ**รายการจ่าย** (ยอด · ใครจ่าย · ใครร่วม · โหมดหาร)
3. เปิดแท็บ **สรุปโอน** → ดูยอดต่อคนและรายการ “ใคร → ใคร”
4. **คัดลอกข้อความ** ไปวางในแชท / ติ๊ก “โอนแล้ว”

### โหมดหารที่รองรับ

| โหมด | ใช้เมื่อ |
|------|---------|
| **หารเท่า** | ทุกคนในรายการรับผิดชอบเท่ากัน |
| **สัดส่วน** | กินไม่เท่า เช่น ช็อต 2:3:1 |
| **ระบุบาท** | กำหนดจำนวนเงินต่อคนเอง |
| **เลี้ยง** | คนจ่ายรับผิดชอบทั้งรายการ (treat) |

## หลักการคำนวณ

```text
ยอดสุทธิของแต่ละคน = เงินที่จ่ายจริง − เงินส่วนที่ควรกิน/ใช้

  บวก (+)  → จ่ายเกิน  ควรได้คืน
  ลบ  (−)  → กินเกิน  ต้องโอนออก
  ศูนย์    → ลงตัว

จากนั้นระบบย่อเป็นรายการโอนจำนวนน้อย (greedy settle)
```

เงินเก็บเป็น**สตางค์ (integer)** เพื่อลดปัญหาปัดเศษ
