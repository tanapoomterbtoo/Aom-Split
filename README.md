# Aom Split — หารเงิน

แอปเว็บเบาๆ สำหรับ**หารเงินในกลุ่มเพื่อน**  
บันทึกว่าใครจ่ายอะไร · ใครใช้ส่วนไหน · แล้วสรุปว่า **ใครต้องโอนให้ใคร เท่าไหร่**

ใช้ได้กับทริป ทานข้าว เช่าบ้าน ของใช้ร่วม — แนว Splitwise แบบเบา

## เปิดใช้งาน

### วิธีเร็ว (เปิดไฟล์ตรงๆ)

```bash
open index.html
# หรือดับเบิลคลิก index.html
```

### ผ่าน static server (แนะนำบนมือถือ / เครือข่ายท้องถิ่น)

```bash
npx --yes serve .
# แล้วเปิด URL ที่ขึ้นในเทอร์มินัล
```

### บันทึกข้อมูลอัตโนมัติ

- ทุกทริป / รายการจ่าย / สถานะโอน ถูก**บันทึกอัตโนมัติ**ในเบราว์เซอร์เครื่องนี้ (`localStorage` · key `aom_split_v1`)
- เปิดเว็บเดิมบนเครื่องเดิม → เจอข้อมูลเดิม
- หน้าแรกมีปุ่ม **ส่งออกสำรอง / นำเข้าสำรอง** (ไฟล์ `.json`) ไว้ย้ายเครื่องหรือกันข้อมูลหาย

### แชร์กับเพื่อน — Google Sheet เป็น DB กลุ่ม (พร้อมใช้)

แอป**เชื่อมฐานข้อมูลกลุ่มอัตโนมัติ** — ทุกคนเปิดลิงก์เดียวกันแล้วใช้ได้เลย ไม่ต้องใส่ URL/token

- เปิดแอป → ซิงก์ทริปกลุ่มทันที  
- สร้าง/แก้รายการ → อัปขึ้น Sheet ชุดเดียวกันอัตโนมัติ  
- **ซิงก์อัตโนมัติ:** ดึงของเพื่อนทุก ~12 วินาที · กลับมาที่แท็บ/เน็ตกลับ → ดึงใหม่  
- เพื่อนเปิดเครื่องอื่น → เห็นทริปชุดเดียวกันโดยไม่ต้องกดซิงก์  
- ยัง cache ในเบราว์เซอร์ — ออฟไลน์ใช้ต่อได้  

| | |
|--|--|
| โค้ดฝั่ง Sheet | `apps-script/Code.gs` (สำรองไว้ถ้าต้อง redeploy) |
| คู่มือ backend | `apps-script/README.md` |
| conflict | ใครบันทึกล่าสุดชนะ (`updatedAt`) |

> Sheet นี้เป็นของกลุ่มในโค้ดแอป — ใครเปิดเว็บก็เข้าถึงทริปกลุ่มได้

## วิธีใช้ (สั้นๆ)

1. เปิด **หน้าแรก** → **สร้างทริปใหม่** ใส่ชื่อทริปและชื่อเพื่อน
2. เพิ่ม**สมาชิก**และ**รายการจ่าย** (ยอด · ใครจ่าย · ใครร่วม · โหมดหาร)
3. เปิดแท็บ **สรุปโอน** → ดูยอดต่อคนและรายการ “ใคร → ใคร”
4. **คัดลอกข้อความ** ไปวางในแชท / ติ๊ก “โอนแล้ว”

### โหมดหารที่รองรับ

| โหมด | ใช้เมื่อ |
|------|---------|
| **หารเท่า** | ทุกคนในรายการรับผิดชอบเท่ากัน |
| **สัดส่วน** | ใช้ไม่เท่า เช่น สัดส่วน 2:3:1 |
| **ระบุบาท** | กำหนดจำนวนเงินต่อคนเอง |
| **เลี้ยง** | คนจ่ายรับผิดชอบทั้งรายการ (treat) |

### พร้อมเพย์ (จ่ายยอดตามสรุป)

ผู้รับเงินกรอก **เบอร์มือถือ** หรือ **เลขบัตรประชาชน** ที่ผูกพร้อมเพย์ในแท็บสมาชิก  
ตอน **สรุปโอน** ผู้จ่ายกด **พร้อมเพย์** → สแกน QR ยอดตามที่ต้องโอน

- Payload มาตรฐาน EMVCo / BOT (แนว [saladpuk/PromptPay](https://github.com/saladpuk/PromptPay) + [dtinth/promptpay-qr](https://github.com/dtinth/promptpay-qr))
- ระบุยอดใน QR แล้ว — ไม่ต้องพิมพ์จำนวนเอง

## หลักการคำนวณ

```text
ยอดสุทธิของแต่ละคน = เงินที่จ่ายจริง − เงินส่วนที่ควรกิน/ใช้

  บวก (+)  → จ่ายเกิน  ควรได้คืน
  ลบ  (−)  → กินเกิน  ต้องโอนออก
  ศูนย์    → ลงตัว

จากนั้นระบบย่อเป็นรายการโอนจำนวนน้อย (greedy settle)
```

เงินเก็บเป็น**สตางค์ (integer)** เพื่อลดปัญหาปัดเศษ
