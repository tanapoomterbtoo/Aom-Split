# Aom Split — หารเหล้า

แอปเว็บเบาๆ สำหรับ**เพื่อนไปกินเหล้าด้วยกัน**  
บันทึกว่าใครจ่ายอะไร · ใครกินเท่าไร · แล้วสรุปว่า **ใครต้องโอนให้ใคร เท่าไหร่**

ไม่ใช่ระบบ POS ร้าน — เป็นตัวช่วยหารบิลในกลุ่มเพื่อน (แนว Splitwise เฉพาะทริปกินดื่ม)

## 🌐 Live (GitHub Pages)

**https://tanapoomterbtoo.github.io/Aom-Split/**

Source: branch `main` · folder `/` (root)

## เปิดใช้งาน

### วิธีเร็ว (เปิดไฟล์ตรงๆ)

```bash
open index.html
# หรือดับเบิลคลิก index.html
```

### ผ่าน static server (แนะนำบนมือถือ / เครือข่ายท้องถิ่น)

```bash
npx --yes serve .
# แล้วเปิด URL ที่ขึ้นในเทอร์มินัล
```

ข้อมูลถูกเก็บใน **localStorage** ของเบราว์เซอร์ (`aom_split_v1`) — ไม่มีเซิร์ฟเวอร์หลังบ้าน

## วิธีใช้ (สั้นๆ)

1. เปิด **หน้าแรก** → **สร้างทริปใหม่** ใส่ชื่อทริปและชื่อเพื่อน
2. เพิ่ม**สมาชิก**และ**รายการจ่าย** (ยอด · ใครจ่าย · ใครร่วม · โหมดหาร)
3. เปิดแท็บ **สรุปโอน** → ดูยอดต่อคนและรายการ “ใคร → ใคร”
4. **คัดลอกข้อความ** ไปวางในแชท / ติ๊ก “โอนแล้ว”

### โหมดหารที่รองรับ

| โหมด | ใช้เมื่อ |
|------|---------|
| **หารเท่า** | ทุกคนในรายการรับผิดชอบเท่ากัน |
| **สัดส่วน** | กินไม่เท่า เช่น ช็อต 2:3:1 |
| **ระบุบาท** | กำหนดจำนวนเงินต่อคนเอง |
| **เลี้ยง** | คนจ่ายรับผิดชอบทั้งรายการ (treat) |

## หลักการคำนวณ

```text
ยอดสุทธิของแต่ละคน = เงินที่จ่ายจริง − เงินส่วนที่ควรกิน/ใช้

  บวก (+)  → จ่ายเกิน  ควรได้คืน
  ลบ  (−)  → กินเกิน  ต้องโอนออก
  ศูนย์    → ลงตัว

จากนั้นระบบย่อเป็นรายการโอนจำนวนน้อย (greedy settle)
```

เงินเก็บเป็น**สตางค์ (integer)** เพื่อลดปัญหาปัดเศษ

## Deploy บน GitHub Pages

| รายการ | ค่า |
|--------|-----|
