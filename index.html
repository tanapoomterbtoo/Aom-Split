☁️ Google Sheet (แชร์กับเพื่อน)

เฉพาะเครื่อง

ใช้ Sheet เป็นฐานข้อมูลกลาง — เพื่อนใส่ URL + token ชุดเดียวกัน แล้วเห็นทริปเดียวกัน

ยังไม่ได้เชื่อม Sheet — ข้อมูลอยู่แค่เบราว์เซอร์นี้
วิธีตั้งค่าครั้งแรก (คนเดียวในกลุ่ม)
  1. สร้าง Google Sheet ใหม่ → Extensions → Apps Script
  2. วางโค้ดจากโฟลเดอร์ apps-script/Code.gs ใน repo
  3. รัน setupOnce หนึ่งครั้ง → คัดลอก token
  4. Deploy → Web app → access Anyone → คัดลอก URL
  5. ใส่ URL + token ด้านบน แล้วส่งชุดเดียวกันให้เพื่อน

รายละเอียดเต็ม: ไฟล์ apps-script/README.md
